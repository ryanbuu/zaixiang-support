技术支持隐私政策

隐私政策

适用于再响 iOS App · 更新日期：2026年10月11日

数据的使用

再响无需注册账号。App 不向开发者服务器上传闹钟设置或使用记录，不包含广告、统计分析或追踪 SDK。

闹钟名称、时间、重复规则、稍后提醒设置、补响设置及系统登记标识保存在本机 App 存储空间，用于显示、调度、同步和取消闹钟。这些数据可能根据你的系统设置参与设备备份。

系统权限与共享

App 请求 AlarmKit 闹钟权限，用于由 iOS 安排和执行系统闹钟。闹钟名称与所需调度信息会交给 iOS 系统，用于响铃界面、锁屏和实时活动。App 不将这些信息分享给广告商或其他第三方服务。

App 不请求通讯录、定位、照片或麦克风权限，不读取系统铃声资源目录。铃声由 AlarmKit 的系统默认声音接口提供。

保存与删除

闹钟数据保留在设备上，直到你删除对应闹钟或卸载 App。删除闹钟时，App 会请求系统取消对应的全部已登记闹钟；若系统取消失败，App 会保留登记标识并显示错误，以便重试。建议卸载前先在 App 中删除闹钟。已有设备备份的保留和删除由你的系统备份设置管理。

撤销权限

你可以在 iOS 设置中关闭再响的闹钟权限，或在 App 中关闭、删除闹钟。无需注销账号。

技术支持与网站访问

支持页面和隐私政策由 GitHub Pages 托管。访问网站时，GitHub 可能按其自身隐私声明处理 IP 地址和访问日志。通过 GitHub Issues 提交的问题及你主动提供的内容会公开展示，并用于排查和回复问题；请勿提交个人或敏感信息。App 本身没有内置问题上传功能。
